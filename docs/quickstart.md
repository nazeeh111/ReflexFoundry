# Quickstart

ReflexFoundry is a local Python tool. Start with the model-free demo, inspect what it measures, then run training if the workload is relevant to you.

## Install from source

Use Python 3.11 or newer. On macOS or Linux:

```bash
git clone https://github.com/nazeeh111/ReflexFoundry.git
cd ReflexFoundry
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
reflex --version
reflex specs
```

On Windows, activate the environment with `.venv\Scripts\Activate.ps1` in PowerShell. Cross-platform Python support does not imply every optional GPU runtime is available on every system.

## Execute the small demo

```bash
reflex benchmark --output runs/first-look --small --repeats 3
reflex discover --workspace runs/first-look
reflex lab --workspace runs/first-look --output runs/first-look/lab.html
```

Open `runs/first-look/lab.html`. For the live read-only view:

```bash
reflex serve --workspace runs/first-look --port 8765
```

Open the printed loopback address. Stop the server with Ctrl-C. It reads local artifacts and accepts no browser deployment commands.

The demo generates small Python packages, applies candidate patches, executes focused and full tests in alternating order, and checks public behavior with separate grader code. No durations or correctness outcomes are simulated. The small dataset is too small to train or promote a policy.

`--output` must name a new or empty benchmark directory. Use a new versioned directory for another run; preserve the old evidence when comparing results.

## Record a decision you explicitly choose to share

Create `decision.json`:

```json
{
  "id": "display-fix-001",
  "authorized": true,
  "repository": "my-local-project",
  "spec": "test-scope-v1",
  "inputs": {
    "summary": "Fix display formatting in the labels module.",
    "changed_files": ["src/labels.py"]
  },
  "selected": "focused"
}
```

Then:

```bash
reflex observe decision.json --workspace .reflex --consent
reflex discover --workspace .reflex
```

`authorized: true` and `--consent` are both required. Review the source record before ingestion. Common secret patterns, emails and home-directory identifiers are redacted, but automated redaction is not a complete privacy guarantee. A selected action is an observation, not proof that it improved a task. Without measured independent outcomes, discovery reports insufficient outcome evidence.

## Run the full training experiment

```bash
python -m pip install -e '.[train]'
reflex benchmark --output runs/experiment-v1 --repeats 3
reflex download --output models/base
reflex train --workspace runs/experiment-v1 \
  --base models/base --output models/policy-v1 --epochs 4
reflex evaluate --workspace runs/experiment-v1 \
  --policy models/policy-v1 --base models/base --backend torch
reflex lab --workspace runs/experiment-v1 --output runs/experiment-v1/lab.html
```

For native Apple Silicon inference, install `python -m pip install -e '.[apple]'` and select `--backend mlx` when evaluating or deciding. `auto` selects MLX on Apple Silicon and PyTorch elsewhere. A restricted or headless macOS session may lack GPU access; use a suitable local session or explicitly select the portable backend. Respect permission denials.

Training freezes the encoder and adapts the Laya decision head. Only the training split reaches the upstream trainer. External calibration selects an abstention threshold; independent promotion and test groups check it. Review the exact manifest and report generated by your version. The base checkpoint download is substantial and optional.

The training extra requires Git and resolves Laya from the immutable upstream source revision recorded in the package metadata. The source's declared Laya 0.4.16 version was unavailable on PyPI at release preparation, so this project does not depend on a nonexistent index release. Optional MLX installation is separate.

## Read the report before shadowing

| Artifact | Purpose |
| --- | --- |
| `records.jsonl` | Inputs, split membership, choices and measured candidate outcomes. |
| `manifest.json` in the benchmark folder | Fixture generation parameters, hashes, trial count and limits. |
| `manifest.json` in the policy folder | Training provenance, base revision and model hashes. |
| `predictions.json` | Local and optional unadapted baseline predictions and timing. |
| `evaluation.json` / `report.json` | Calibration, promotion, test results and deployment rejection reasons. |
| `policy.json` | Registered model and evidence bindings. Local model paths stay local. |
| `deployment.json` / `requests.json` | State transitions, bounded decisions, checked outcomes and rollback history. |

The report may reject the policy. In particular, a small focused test often costs less than cold model startup; a simple heuristic may already be better. Preserve that finding instead of changing thresholds after seeing test results.

## Shadow, verify, then consider bounded use

```bash
reflex shadow --workspace runs/experiment-v1 --policy models/policy-v1
```

Shadow mode returns the original fallback while recording a proposed candidate. Follow the [Codex guide](codex.md) to check that candidate independently. Successful fallback runs cannot establish that the proposal was safe.

Only if the registered evaluation permits deployment and sufficient eligible shadow candidates have independently passed:

```bash
reflex deploy --workspace runs/experiment-v1 --policy models/policy-v1 \
  --opt-in --max-decisions 100
```

The gate can refuse this command. Do not manually edit local evidence to bypass it. Roll back with:

```bash
reflex rollback --workspace runs/experiment-v1
```

ReflexFoundry returns advice. Your agent executes actions through its own tools and permission controls, and still runs checks required by your repository.
